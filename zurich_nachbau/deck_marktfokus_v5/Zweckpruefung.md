# Zweckprüfung: Hilft jedes Element der Story? (Marktfokus v5, 12.11.2026)

Frage je Element: Welche Aussage trägt es? Würde ohne es etwas fehlen? Gibt es eine Darstellung, die es besser zeigt?

| Folie | Element | Zweck | Entscheidung |
|---|---|---|---|
| 1 | Drei Icons auf dem Band | ohne Beschriftung nur Deko | **beschriftet** (Cyber, Gesundheit, Logistik): nennt die drei Segmente schon auf dem Titel |
| 2 | Icon je Karte | wird zum Wegweiser, wenn dasselbe Icon auf den Belegfolien wiederkehrt | **behalten**, Kapitelmarke jeder Folie trägt jetzt dasselbe Icon |
| 2 | Große Zahl + Vergleichspaar | Beleg der Behauptung in einer Sekunde | behalten |
